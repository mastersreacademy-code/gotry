# GoTry

GoTry is a proposed Cloudflare Workers app for children's introductory activity discovery and booking.

## Status
Initial repository bootstrap. No production deployment is configured. No real payments are enabled.

## Planned journey
1. Provider registers business and submits an activity.
2. Provider configures trial and regular lessons.
3. Admin reviews listings.
4. Parents register interest for free.
5. Group trial proceeds when sufficient interest is confirmed; individual trials are scheduled separately.
6. Sandbox payment and attendance confirmation follow once verified.

The $2 amount in draft mockups is not a confirmed production fee.
